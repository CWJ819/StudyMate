# 联调演示脚本（5 分钟版）

配套前端 `frontend/`（F0–F5）。演示主线一句话：**把课件喂进去，它告诉你今天复习什么、哪里薄弱、考什么。**

## 准备（演示前 5 分钟）

```bash
# 1. 后端（仓库根目录；演示数据在本地 sqlite，不碰真实服务）
LLM_BASE_URL=mock://local python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2. 前端
cd frontend && npm run dev    # http://localhost:5173
```

- mock 模型即时返回，全程无 API 配额消耗；顶部黄色横幅是刻意保留的演示模式标识。
- 若要全新数据：删 `data/studymate.db` 后 `alembic upgrade head` 重建。

## 流程与讲解词

| # | 操作 | 讲解词 | 观众看到 |
|---|------|--------|----------|
| 1 | 首页新建课程「计算机网络·运输层」 | 每门课一个独立空间 | 课程卡片 |
| 2 | 资料 tab 上传 PDF（可提前准备一份含扫描页的） | 支持课件 PDF/PPTX，逐页解析；扫描页会如实标注“无可提取文本”而不是假装看懂 | 状态从排队→处理中→完成（带警告） |
| 3 | 知识框架 tab 点「构建知识框架」 | 从材料大纲抽知识树，每个知识点挂原文出处——点开“慢启动”的来源，直接跳到讲义第 18 页原文 | 构建中→树形展开，出处内联展开 |
| 4 | 测验 tab 直接「出题」（默认全部叶子、10 题） | 出题范围就是刚才那棵树的叶子；题型混合单选/多选/简答 | 出题中→作答页 |
| 5 | 现场作答（答错一两道更有戏剧性）→ 提交 | 客观题即时判分，简答题模型按要点批改；提交是幂等的——网络抖动重试不会重复扣分或重复提交 | 结果页：答对/答错/部分得分/待批改，逐题反馈 |
| 6 | 复习 tab | 答题记录汇成掌握度估计（升序条形，灰条=未测验≠薄弱）；下面是错题本，每条带证据（作答 N · 低分 N） | 掌握度列表 + 错题本 |
| 7 | 复习页右侧「练一轮薄弱点」 | 不用自己挑：系统按缺口选节点直接再出一组 | 跳回测验页出新题 |
| 8 | 复习计划 tab：考试日设 10 天后、每日 60 分钟，生成 | 任务按天排好，每天合计不超上限；完成打勾即迁移状态，终态只读 | 按天分组的任务清单 + 版本历史 |
| 9 | 总览 tab | 回到主页：倒计时、今日任务、最近薄弱点；点左栏薄弱点，右栏对应掌握度条高亮——两栏是同一份数据 | 总览页联动 |
| 10 | 设置页（顶栏「设置」） | 演示模式的说明和退出方法都在这；数据库路径等服务器配置不展示 | 只读配置 |

## 故障预案

- **偶发 `database is locked`**（SQLite + 进程内 job 线程，已知 P2）：稍等重试即恢复，不影响数据。
- **未配置 LLM 的后端**：出题/构建提示“尚未配置模型，请先在设置中配置”——这是预期行为，不是 bug。
- **提交时断网**：答案与幂等键都在本地草稿里，恢复后重试返回同一份结果。
- **刷新页面**：测验结果、今日任务状态都还在（后端持久化 + 本地草稿）。
